# AI Resume Analyzer

## Problem

Job seekers often do not know:
- Whether their resume matches a job description
- Which skills are missing
- How ATS systems view their resume

## Solution

An AI-powered system that:

1. Accepts a resume upload
2. Extracts resume data
3. Accepts a job description
4. Compares resume vs job description
5. Provides a match score
6. Suggests improvements

## Future Features

- ATS score
- Skill gap analysis
- Resume improvement suggestions
- Cover letter generation
- Resume version tracking
